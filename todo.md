# Product roadmap

The authoritative audit, acceptance criteria, and release evidence live in [docs/PRODUCTIZATION.md](docs/PRODUCTIZATION.md).

## P1: next release candidates

- Add real stage streaming and user cancellation with a durable generation state model.
- Add story editing/regeneration with version history and recovery.
- Add a story bible/codex that controls what context is sent to providers.
- Add opt-in live-provider contract tests and token/cost telemetry without exposing content or keys.
- Complete keyboard, assistive-technology, and cross-browser verification.

## P2: only after evidence

- Repair or replace the isolated collection/tag/favorite schema before exposing archive organization UI.
- Certify selected local/OpenAI-compatible model servers.
- Evaluate PDF/EPUB export after Markdown export usage is understood.
- Evaluate a hosted multi-user profile only with approved identity, operations, privacy, abuse, billing, and licensing plans.

## Owner decisions

- Have qualified counsel review the BSL parameters, historical copyright chain, contributor agreement needs, and commercial-license terms.
- Run a trademark clearance search and decide whether to seek federal registration for Samsarix and Samsarix Story Studio.
- Decide whether the optional MySQL profile should remain supported.
- Approve any hosted deployment, telemetry, package publication, billing, or paid-provider verification.
