# Support

For setup help, bug reports, and product support, email [support@samsarix.com](mailto:support@samsarix.com) or open a GitHub issue that contains no credentials or private story text.

Report suspected vulnerabilities privately according to [SECURITY.md](SECURITY.md). Send licensing, partnership, and other business questions to [contact@samsarix.com](mailto:contact@samsarix.com).

This repository is provided without a guaranteed response time or support service level unless a separate written agreement says otherwise.
